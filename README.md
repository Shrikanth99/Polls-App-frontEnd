# 🗳️ Polls App

A full-stack **Polls Application** built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js), allowing users to create polls, vote, and view results in real-time.

---

## 🚀 Features

✅ User registration & authentication (JWT)  
✅ Create, edit, delete polls  
✅ Vote on active polls  
✅ View poll results and analytics  
✅ Dynamic poll listings and filtering  
✅ Responsive UI with **React Bootstrap**  
✅ Secured backend APIs with JWT and Bcrypt  

---

## 🛠️ Tech Stack

| Frontend | Backend | Database |
|----------|---------|----------|
| React.js  | Node.js + Express.js | MongoDB |

Other Libraries: Redux, Context API, React Bootstrap, Material UI, Axios, JWT, Bcrypt.js
